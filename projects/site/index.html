For a while now, I've always been interested in the idea of being able to have my own website. I'm unfortunately a bit too young to have experienced the era where everybody had their own website and were ripping HTML and CSS so that they can have their own website look like whatever site they wanted. Not that I'm inspired by ripping existing code and whatnot, but the general idea of just having a central hub that isn't on some proprietary site like LinkedIn is much more appealing. I understand that LinkedIn and Handshake and everything else is a nice professional platform, but it doesn't feel like I can fully express myself on those sites. So, I just wanted to have my own.

But back to the project itself. This website is hosted through CloudFlare pages, which I chose because I also registered the domain through CloudFlare. I'm learning the necessary HTML and CSS as I go. I'm pretty much at a point where I'm happy with the aesthetics of this website, so it probably won't change much from what it is now unless I feel some urge to do a big time visual revision to the entire site.
